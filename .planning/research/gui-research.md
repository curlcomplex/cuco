# JSFX GUI — Library Research

Research into community GUI libraries for JSFX, oriented around building a
suite of lightweight, gesture-driven CUCO plugins that pair with the
Keyframe / Random Walk envelope-writing scripts.

## TL;DR

Build on **`geraintluff/jsfx-ui-lib`** (`Tukan/ui-lib.jsfx-inc`, already on
disk) plus a project-local `cuco_theme.jsfx-inc` that defines the CUCO
palette and wraps the library's slider primitives into a radial knob and an
XY pad. Avoid Tukan's `tk_lib` wrapper — it couples you to his visual style.
Pair with cookdsp for DSP primitives.

## Tukan's secret: it's Geraint Luff's library

Tukan ships `ui-lib.jsfx-inc` (2,970 lines, 241 functions) inside his plugin
folder. The header (`Generated by jsfx-preprocessor`) and namespace
(`ui_*`, `uix_*`, `control_*`) confirm it is the public
`geraintluff/jsfx-ui-lib` (54★, the canonical home). Tukan's "look" comes
from his theme + image assets, not the library itself.

### What the library provides

- **Layout engine** — `ui_split_top/bottom/left/right`, `ui_push_rect`,
  `ui_pad`, ratio- and text-relative splits. Box-model layout, no manual
  pixel math.
- **Screen stack** — `ui_screen_open/close`, multi-page UIs with arguments.
- **Themed controls** — `control_slider_x/_y`, `control_button`,
  `control_selector`, `control_navbar`, `control_arrow`, `control_readout`,
  `control_group`. State-aware backgrounds (enabled / passive / disabled /
  inset / technical) and finishes (gloss, circle shade, dotted lines).
- **Mouse model** — `ui_drag/_x/_y`, `ui_press`, `ui_clickcount`, with
  double-click and drag-threshold detection built in.
  **`ui_automate(slider, value)`** writes the slider *and* posts an undo
  point — this is the correct integration point for envelope-writing
  workflows, not direct slider assignment.
- **Graphs** — `ui_graph`, `ui_graph_step` for waveform / curve displays.
- **Retina / HiDPI** — `_retina` variants on geometry getters; one-line
  setup with `gfx_ext_retina = 1`.
- **Theming** — `control_start(defaultPage, theme, imageBuffer)` takes a
  theme. Colors flow through `ui_color()` and
  `uix_control_color_from_theme()`. Fully customizable.

### Programming model

Immediate-mode, like Dear ImGui. Each `@gfx` frame you re-declare the UI
tree:

```jsfx
@gfx 600 400
ui_start();
  ui_split_top(40);
    control_navbar("CUCO Smear");
  ui_pop();
  ui_pad(8);
  ui_split_left_ratio(0.5);
    control_slider_x(slider1, 0, 1, 0);  // slider1 ref, range, curve
  ui_pop();
  control_slider_x(slider2, 0, 1, 0);
ui_system();
```

Costs live entirely in `@init` / `@gfx`. Zero audio-thread overhead.

## Plan for the CUCO suite

1. **`cuco_theme.jsfx-inc`** — palette (muted, high-contrast, restrained),
   font choices, padding/spacing constants, theme struct that drops into
   `control_start()`.
2. **`cuco_widgets.jsfx-inc`** — wrappers ui-lib doesn't ship:
   - `cuco_knob(value, lo, hi, curve)` — radial via `gfx_arc`, since
     ui-lib's stock controls are linear sliders.
   - `cuco_xy_pad(x_slider, y_slider, ...)` — 2D surface for sweeping two
     parameters together. Strong fit for gestural automation.
   - `cuco_curve_display(buffer, len)` — small inline visualization for
     "what is this slider doing right now" feedback.
   - `cuco_meter(level)` — minimal, fast.
3. **One reference plugin** built against the above to validate the
   integration before scaling out the suite.
