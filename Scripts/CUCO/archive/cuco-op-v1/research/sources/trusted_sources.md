# Trusted Sources for CUCO-OP System Functions Research

This document defines authoritative sources for researching complex mathematical and music theory concepts. Only sources meeting these criteria should be used for implementation-critical research.

## Source Validation Criteria

### Primary Sources (Highest Authority)
- **Academic Publications**: Peer-reviewed journals, conference proceedings
- **Authoritative Textbooks**: Recognized standard references in the field
- **Official Specifications**: IEEE standards, formal mathematical definitions
- **Primary Literature**: Original papers introducing concepts or algorithms

### Secondary Sources (Supporting Authority)
- **University Course Materials**: From recognized academic institutions
- **Technical Documentation**: Well-documented library implementations
- **Reference Works**: Mathematical handbooks, encyclopedias
- **Expert Analysis**: Detailed explanations by recognized experts

### Verification Requirements
- **Cross-Reference**: Minimum 2 independent authoritative sources
- **Mathematical Rigor**: Formal proofs or derivations provided
- **Implementation Examples**: Working code or detailed pseudocode available
- **Peer Review**: Source has undergone scholarly review process

## Music Theory & Composition

### Counterpoint & Voice Leading
- **Fux, Johann Joseph**: *Gradus ad Parnassum* (1725) - Species counterpoint foundation
- **Piston, Walter**: *Harmony* (5th Edition) - Standard harmony and voice leading
- **Schenker, Heinrich**: *Free Composition* - Linear analysis and voice leading
- **Salzer, Felix**: *Structural Hearing* - Schenkerian analysis applications

### Atonal & Serial Techniques
- **Schoenberg, Arnold**: *Style and Idea* - Twelve-tone theory foundations
- **Perle, George**: *Serial Composition and Atonality* - Serial technique analysis
- **Forte, Allen**: *The Structure of Atonal Music* - Set theory applications
- **Rahn, John**: *Basic Atonal Theory* - Mathematical foundations of atonality

### Algorithmic Composition
- **Roads, Curtis**: *Composing Electronic Music* - Computer music techniques

### Jazz & Popular Music Theory

## Source Validation Protocol

### For Each Research Project
1. **Primary Source Identification**: Locate original or most authoritative source
2. **Cross-Validation**: Find 1-2 additional independent authoritative sources
3. **Mathematical Verification**: Verify all formulas and algorithms against multiple sources
4. **Implementation Validation**: Check existing implementations if available
5. **Expert Review**: Consult recognized experts in the field when possible

### Red Flags (Avoid These Sources)
- ❌ Wikipedia as sole source (use only for initial orientation)
- ❌ Blog posts without academic backing
- ❌ Forum discussions or Q&A sites
- ❌ Unverified online tutorials
- ❌ Sources without mathematical rigor or formal analysis
- ❌ Commercial software documentation without theoretical backing

### Source Documentation Requirements
For each source used:
- Full citation with author, title, publication, year
- Page numbers or section references for specific concepts
- Assessment of source authority and credibility
- Cross-reference validation notes
- Implementation-specific insights extracted
